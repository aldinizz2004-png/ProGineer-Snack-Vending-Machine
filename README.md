The system is divided into small responsibilities. SnackMachine coordinates the transaction, Inventory manages slot lookup, each Slot stores its snacks using a Stack, and CashVault manages available cash denominations and exact change. I used the State Pattern to control valid operations during Idle, Payment, and Dispensing states. Hardware behavior is separated through IDisplay and IDispenser, which are injected into the machine to keep the business logic testable and independent from concrete hardware. Before committing a purchase, the machine validates stock, payment, and exact change to avoid partial transactions.
